# 📊 Data Analysis and Data Visualization Project

This repository contains a basic data analysis workflow using Python.  
The project focuses on loading datasets, exploring their structure, and creating visualizations to understand data patterns and detect insights.
 **Objectives**
In this project, the following tasks are performed:
- Load dataset using the **Pandas library**
- Understand dataset structure using:
  - `.shape`
  - `.columns`
  - `.head()`
- Perform basic **Exploratory Data Analysis (EDA)**
- Create visualizations using **Matplotlib** and **Seaborn**

--- **Tools & Libraries Used**

- Python 
- Pandas
- NumPy
- Matplotlib
- Seaborn
